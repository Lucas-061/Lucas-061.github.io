# Lucas-061 Personal Homepage

This repository contains the source for a personal GitHub Pages site.

## Features

- Markdown-driven home and project sections.
- Offline map notes with local point selection on `static/map/images/fuzhou.jpeg`.
- Blog-style note editor with Markdown preview and pasted image support.
- Default published map notes are loaded from `static/data/maps/map-notes.json`.
- Map-note management documentation lives in `docs/map-notes.md`.
